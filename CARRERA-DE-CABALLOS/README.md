# Carrera de Caballos — Desafíos Locos

Juego local para dos competidores: caballo rosa contra caballo azul.

## Ejecutar
1. Descarga esta carpeta o el repositorio.
2. Abre `index.html` con Microsoft Edge o Google Chrome.
3. No requiere instalación, internet ni dependencias externas.

Compatible con Windows 10 de 32 y 64 bits y Windows 11 de 64 bits, siempre que se use una versión compatible de Edge o Chrome.

## Controles predeterminados
- Rosa: tecla **A** o botón USB configurado para enviar la tecla A.
- Azul: tecla **L** o botón USB configurado para enviar la tecla L.
- También puedes pulsar los botones grandes en pantalla.
- Enter inicia la carrera.

Para pulsadores arcade USB, configura el encoder para que cada botón envíe una tecla distinta (A y L). Si el encoder permite cambiar teclas, puedes elegir otras desde el panel del juego.

## Mecánica
Cada competidor completa 5 pulsaciones para avanzar. El contador se reinicia automáticamente después de cada avance. Gana quien llegue primero a la meta. La cantidad de pulsaciones y el avance por ciclo son editables.

## Personalización
En el panel de edición puedes cambiar:
- Imagen del caballo rosa y del caballo azul (PNG, JPG o WebP).
- Fondo de la pista.
- Música de carrera.
- Efecto de pulsación y efecto de victoria.
- Teclas de cada competidor.
- Nombres, dificultad, pulsaciones por avance, volumen y tamaño de avance.
- Activar instrucciones habladas y escritas o dejar solo las escritas.

Los archivos seleccionados se usan localmente en el navegador; no se suben a GitHub.

## Dificultad
- Fácil: avance predeterminado de 10% por grupo de pulsaciones.
- Difícil: avance predeterminado de 7% por grupo, por lo que requiere más ciclos para llegar a la meta.
- Puedes personalizar el porcentaje y las pulsaciones en ambos modos.

## Notas
La voz utiliza la función de síntesis de voz del navegador y depende de las voces instaladas en Windows. Para que la música y los efectos suenen, inicia la carrera o interactúa primero con la pantalla (restricción de reproducción automática del navegador).
